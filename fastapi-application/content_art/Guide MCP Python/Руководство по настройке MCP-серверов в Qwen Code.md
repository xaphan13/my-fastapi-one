Давайте разберем пошагово, куда именно складывать файлы, как прописать настройки в settings.json и как перенести эту конфигурацию в markdown-манифест вашего субагента.

### Шаг 1\. Куда сложить Python-скрипт MCP-сервера?

Вы можете сохранить ваш скрипт (например, server.py) в **любую удобную папку** на компьютере 1\. Однако на практике лучше придерживаться следующих правил:

* **Если сервер нужен только для одного конкретного проекта**:Создайте в корне проекта отдельную папку (например, scripts/ или .qwen/) и положите файл туда:  
* *Пример пути:* /Users/username/my-project/scripts/server.py  
* **Если сервер глобальный (нужен во всех проектах)**:Положите его в вашу домашнюю директорию или в глобальную папку настроек Qwen Code:  
* *Пример пути:* \~/.qwen/scripts/server.py

**Самое главное правило:** в конфигурационных файлах всегда нужно указывать **полный абсолютный путь** к этому скрипту 2\. Относительные пути использовать нельзя, так как рабочая директория субагента в процессе работы может меняться 3\.

### Шаг 2\. Как прописать запуск в settings.json?

В зависимости от того, хотите ли вы, чтобы этот сервер был доступен везде или только в рамках одного проекта, выберите нужный файл settings.json 4-6:

* **Глобально:** откройте файл \~/.qwen/settings.json 4, 5\.  
* **Для конкретного проекта:** откройте файл .qwen/settings.json в корне вашего проекта 4, 5\.

Добавьте в JSON-структуру секцию **mcpServers** (если её еще нет) и пропишите туда запуск вашего скрипта через uv 7-10:  
{  
  "mcpServers": {  
    "my-python-server": {  
      "command": "uv",  
      "args": \[  
        "run",  
        "/absolute/path/to/your/scripts/server.py"  
      \],  
      "description": "Мой кастомный Python MCP-сервер для автоматизации задач"  
    }  
  }  
}

* **my-python-server** — это придуманный вами алиас (имя) сервера в системе 7, 9\.  
* **command** указывает запустить менеджер пакетов uv 8, 10\.  
* **args** передает аргументы: команду run и **абсолютный путь** к вашему скрипту 8, 10\.  
* *Примечание для Windows:* В путях JSON используйте двойные обратные слэши (\\\\) или прямые слэши (/) 2, 11\.

### Шаг 3\. Как настроить это в markdown-файле субагента?

Файлы декларативного описания субагентов — это Markdown-документы (.md) с блоком метаданных в формате YAML (frontmatter) в самом начале 12-14.

#### 1\. Где создать файл субагента?

* **Для одного проекта:** создайте файл .qwen/agents/my-agent.md в папке проекта 6, 15, 16\.  
* **Глобально:** создайте файл \~/.qwen/agents/my-agent.md 6, 15, 16\.

#### 2\. Что прописать внутри файла?

Вы можете объявить конфигурацию mcpServers прямо во фронтматере субагента 14, 17, 18\. Преимущество этого подхода в том, что данный MCP-сервер будет запускаться **только в момент работы этого субагента**, не нагружая контекст основной сессии в остальное время 17, 19\.  
Запишите структуру в формате YAML между тройными дефисами \--- 12-14:  
\---  
name: python-assistant  
description: "Субагент, использующий кастомные Python-инструменты для обработки файлов. use PROACTIVELY."  
model: inherit  
approvalMode: auto-edit  
mcpServers:  
  my-python-server:  
    command: "uv"  
    args:  
      \- "run"  
      \- "/absolute/path/to/your/scripts/server.py"  
\---

Ты — специализированный субагент-помощник. Твоя цель — решать задачи пользователя, задействуя инструменты подключенного к тебе MCP-сервера \`my-python-server\`.

При работе следуй системным инструкциям и всегда проверяй возвращаемый инструментами результат.

#### Почему это удобно:

1. **Автоматическое окружение:** Благодаря команде uv run, вам не нужно вручную активировать virtualenv или устанавливать библиотеки на компьютер 20, 21\. uv сам подготовит временное окружение и запустит скрипт 20\.  
2. **Изоляция:** Субагент получит доступ к инструментам вашего скрипта (они будут доступны ему с префиксом my-python-server\_\_название\_функции), а при выходе из субагента процесс сервера автоматически завершится 17, 19, 22\.

📊 Я могу показать, как с помощью метаданных (PEP 723\) описать сторонние библиотеки (например, requests или beautifulsoup4) прямо внутри заголовка вашего Python-файла, чтобы uv run сам скачивал их при запуске без создания requirements.txt.
