# Пагинация списков статей (5/10/20)

Прямое задание пользователя без спеки («сразу делай без спеки в файл»): пагинация везде,
где показываются статьи, с выбором количества 5 / 10 / 20. Спека задним числом — для
архива; контракт передавался промптом прогона frontend-dev.

## Подтверждённые решения (от пользователя, 2026-09-01)

- Пагинация везде, где показываются статьи: список на главной (и страницы разделов
  `/section/:name` — тот же компонент) и таблица «Записи реестра» на «Управлении».
- Выбор количества статей на странице: 5 / 10 / 20 (дефолт 10).
- Пагинация клиентская; API не меняется.

## Реализация

- `frontend/src/components/Pagination.tsx` — новый переиспользуемый компонент: «‹ Назад /
  Вперёд ›», счётчик «Страница X из Y» (кликабельные номера при ≤ 7 страницах),
  переключатель 5/10/20, при pageCount ≤ 1 — return null, защитный клампинг.
- `frontend/src/pages/HomePage.tsx` — state page/pageSize, сброс page на 1 при смене
  раздела, срез карточек, `<Pagination>` под сеткой.
- `frontend/src/pages/ArtManagePage.tsx` — та же пагинация для таблицы реестра
  (списки «Новые файлы»/«Записи без файла» не пагинируются).
- `frontend/src/index.css` — `.pagination`, `.page-btn` (+`.active`, `:disabled`),
  `.pagination-size-label`.
