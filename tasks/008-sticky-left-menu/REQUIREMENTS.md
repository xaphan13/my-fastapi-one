# Sticky левое меню при прокрутке статьи

Прямое задание пользователя без спеки: «пункты меню слева не должны уезжать при
прокрутке контента статьи». Мини-правка CSS.

## Подтверждённое решение (от пользователя, 2026-09-01)

- Прокручиваешь статью вниз — левое меню остаётся на месте.

## Реализация

- `frontend/src/index.css`, правило `.left-menu` — добавлены:
  `position: sticky; top: 0; align-self: start; max-height: 100vh; overflow-y: auto;`
  (align-self обязателен в grid-колонке, иначе элемент растянут на высоту строки и не
  прилипает; overflow-y — хвост меню скроллится внутри при большом числе разделов).
  Существующие свойства не тронуты.
