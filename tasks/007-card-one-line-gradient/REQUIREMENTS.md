# Карточка статьи в одну строку + переливающийся заголовок

Прямое задание пользователя без спеки: карточки статей (заголовок/автор/язык) слишком
широкие — собрать в одну строку, заголовок сделать «поярче, переливался разными цветами».

## Подтверждённые решения (от пользователя, 2026-09-01)

- Заголовок, автор и бейдж языка — на одной горизонтальной линии.
- Заголовок — анимированный многоцветный градиент.

## Реализация

- `frontend/src/components/ArticleCard.tsx` — flex-строка (`card-row`): заголовок
  `card-title-grad` (flex:1, ellipsis при переполнении), автор `card-author`,
  бейдж языка `card-lang` (не сжимается).
- `frontend/src/index.css` — `.card-title-grad`: 5-цветный градиент
  `linear-gradient(90deg, …)`, `background-clip: text`, `color: transparent`,
  `background-size: 200% auto`, анимация `card-title-gradient` 6s ease-in-out
  infinite alternate. Отдельный спектр для `[data-theme="light"]` (насыщенные цвета
  для контраста со светлым фоном). `prefers-reduced-motion: reduce` — анимация
  отключается, градиент статичен.
