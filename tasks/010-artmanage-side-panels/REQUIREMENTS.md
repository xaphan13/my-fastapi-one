# Формы управления в боковых панелях-модалках

Прямое задание пользователя без спеки («окно всплывающее для редактирования»), уточнено
вопросами: боковая панель справа; обе формы (редактирование и добавление) — в модалках.

## Подтверждённые решения (от пользователя, 2026-09-01)

- Форма редактирования выбранной статьи — всплывающее окно в виде боковой панели справа.
- Форма добавления записи для нового файла — тоже в модалке (кнопка в секции «Новые файлы»).

## Реализация

- `frontend/src/components/SidePanel.tsx` — новый переиспользуемый компонент: overlay
  (клик → закрытие), `aside role="dialog" aria-modal` с заголовком и ✕, закрытие по Esc
  (keydown-листенер с cleanup, onClose через ref), анимация выезда справа.
- `frontend/src/components/ArtManageForms.tsx` — `ArtEditSelectedForm` получил
  опциональный `onSaved` (вызывается после успешного сохранения; при 422 форма остаётся
  открытой с ошибками по полям).
- `frontend/src/pages/ArtManagePage.tsx` — клик по статье открывает панель редактирования,
  повторный клик закрывает; переключение на другую статью при открытой панели меняет
  запись; «Новые файлы» → кнопка «Добавить запись для нового файла» + вторая панель;
  после «Принять»/«Добавить запись» панель закрывается и контекст перезагружается.
- `frontend/src/index.css` — `.side-panel-overlay` (z-index 1100, над тостами), `.side-panel`
  (`min(480px, 92vw)`, fixed справа), шапка/контент, `@keyframes` выезда,
  `prefers-reduced-motion` — без анимации; старый `.art-edit-panel` удалён.
- Фильтры/список/пагинация/«Добавить все новые файлы»/«Записи без файла» не менялись.
